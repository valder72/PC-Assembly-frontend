# PC Assembly Frontend

Клієнтська частина вебплатформи для конфігурації та підбору комплектуючих ПК. Створена для демонстрації взаємодії з Django REST API на окремому порту за допомогою технології **CORS (Cross-Origin Resource Sharing)**.

---

## 🚀 Функціонал фронтенду

* **Відображення каталогу:** Отримання списку комплектуючих з бекенду (`GET /parts/`) та динамічний рендеринг інтерактивних карток (назва, категорія, виробник, характеристики, ціна, рейтинг).
* **Пошук та фільтрація:**
  * Пошук деталей за назвою у реальному часі.
  * Фільтрація за категорією (динамічно підтягується з `GET /categories/`).
  * Фільтрація за виробником (динамічно підтягується з `GET /manufacturers/`).
* **Додавання комплектуючого:** Модальна форма з валідацією полів та відправкою `POST /parts/` до API.
* **Видалення комплектуючого:** Видалення деталі з підтвердженням дії (`DELETE /parts/:id/`).
* **Моніторинг зв'язку:** Індикатор підключення до бекенд-сервера в шапці сайту.

---

## 🌐 Адреси та порти

| Компонент | Адреса | Порт | Опис |
| :--- | :--- | :--- | :--- |
| **Frontend** | `http://127.0.0.1:5500` (або `http://localhost:5500`) | **5500** | Клієнтський застосунок (Live Server / Python HTTP-сервер) |
| **Backend API** | `http://127.0.0.1:8000` | **8000** | Django REST Framework API з налаштованим CORS |

## 🛠️ Як запустити проєкт

### 1. Переконайтеся, що бекенд запущено
Перед запуском фронтенду запустіть бекенд-сервер у репозиторії `pc_assembly`:
```bash
cd /шлях/до/pc_assembly
source .venv/bin/activate
python manage.py runserver
```
*Бекенд повинен бути активним за адресою `http://127.0.0.1:8000/`.*

### 2. Запуск фронтенду

#### Спосіб 1: Через розширення Live Server (VS Code / JetBrains / PyCharm)
1. Відкрийте папку `pc_assembly_front` у вашому редакторі.
2. Клацніть правою кнопкою миші на файл `index.html`.
3. Оберіть **"Open with Live Server"**.
4. Сторінка автоматично відкриється у браузері за адресою:
   ```text
   http://127.0.0.1:5500/index.html
   ```

#### Спосіб 2: Через вбудований HTTP-сервер Python
Якщо у вас немає Live Server, виконайте у терміналі в папці `pc_assembly_front`:
```bash
python3 -m http.server 5500
```
Після цього відкрийте у браузері: [http://127.0.0.1:5500](http://127.0.0.1:5500).
