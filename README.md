# PC Assembly Frontend

Клієнтська частина вебплатформи для конфігурації та підбору комплектуючих ПК. Створена для демонстрації взаємодії з Django REST API на окремому порту за допомогою технології **CORS (Cross-Origin Resource Sharing)** та захисту ресурсів за допомогою **JWT (JSON Web Tokens)** і рольової моделі авторизації.

---

## 🚀 Функціонал фронтенду

### 1. Аутентифікація та авторизація (JWT)
* **Реєстрація (`register.html`):**
  * Поля: ім'я користувача, ім'я, прізвище, email, пароль та підтвердження пароля.
  * Клієнтська та серверна валідація з виведенням зрозумілих помилок під кожним полем (статус 400).
  * Після успішної реєстрації — автоматичний перехід на сторінку входу.
* **Логін (`login.html`):**
  * Форма входу за `username` та `password`.
  * Збереження пари токенів (`access_token` та `refresh_token`) у `localStorage`.
  * Підтримка повернення: після входу повертає користувача на сторінку, з якої його було перенаправлено (параметр `?next=...`).
  * Захист від повторного входу: вже авторизованого користувача автоматично перенаправляє з форми входу на головну сторінку.
* **Безшовне оновлення токенів (Silent Token Refresh):**
  * Модуль `auth.js` (`authenticatedFetch`) автоматично перехоплює відповіді зі статусом `401 Unauthorized` та надсилає запит з `refresh`-токеном на `/user/token/refresh/`.
  * При успішному оновленні `access`-токен перевипускається, а перерваний запит автоматично повторюється без розриву сесії користувача.
* **Вихід з акаунта (Logout):**
  * Кнопка «Вийти» в шапці сайту видаляє токени з `localStorage` та очищає стан сесії.

### 2. Розмежування прав та сторінки
* **Публічна сторінка (`index.html`):**
  * Доступна всім користувачам без авторизації.
  * Перегляд списку комплектуючих з бекенду (`GET /parts/`), пошук у реальному часі, фільтри за категоріями та виробниками.
  * Неавторизований користувач бачить кнопки «Вхід» та «Реєстрація» і не бачить кнопки «Вийти».
  * Авторизований користувач бачить своє ім'я (наприклад, «Привіт, Ivan!»), статус ролі (Admin) та кнопку «Вийти».
* **Захищена зона (`admin.html`):**
  * Сторінка, доступна виключно авторизованим користувачам.
  * Якщо неавторизований користувач намагається відкрити цю сторінку, його автоматично перенаправляє на `login.html?next=...`.
  * Відображає розширені дані профілю поточного користувача з ендпоінту `/user/me/`.
  * Користувачам з роллю Administrator (`is_staff: true`) надає доступ до форм створення категорій та виробників.

| Компонент | Адреса | Порт | Опис |
| :--- | :--- | :--- | :--- |

## 🛠️ Як запустити проєкт

### 1. Переконайтеся, що бекенд запущено
Перед запуском фронтенду запустіть бекенд-сервер у репозиторії `pc_assembly`:
```bash
cd /шлях/до/pc_assembly
source .venv/bin/activate
python manage.py runserver
```
*Бекенд повинен бути активним за адресою `http://127.0.0.1:8000/`.*

### 2. Запуск фронтенду

#### Спосіб 1: Через вбудований HTTP-сервер Python
У папці `pc_assembly_front` виконайте:
```bash
python3 -m http.server 5500
```
Відкрийте у браузері: [http://127.0.0.1:5500](http://127.0.0.1:5500).

#### Спосіб 2: Через розширення Live Server (VS Code / PyCharm / JetBrains)
1. Відкрийте папку `pc_assembly_front` у редакторі.
2. Клацніть правою кнопкою миші на `index.html`.
3. Оберіть **"Open with Live Server"**.

## 📁 Структура проєкту

```text
pc_assembly_front/
├── index.html        # Головна сторінка: публічний каталог та модальні форми
├── login.html        # Сторінка входу в систему з перевіркою редіректів
├── register.html     # Сторінка реєстрації з валідацією полів
├── admin.html        # Захищена панель для авторизованих користувачів та адмінів
├── auth.js           # Модуль керування JWT (збереження, перевірка, рефреш, інтерцептор)
├── app.js            # Логіка каталогу (отримання деталей, фільтрація, створення/видалення)
├── style.css         # Стилі інтерфейсу (темна тема, адаптивність, форми, картки)
└── README.md         # Документація та інструкція із запуску
```
